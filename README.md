
# NanoGPT ImageGeneration
A experimental custom node for NanoGPT image generation.<br />
<br />
Use directly on ComfyUI or via SillyTavern, OpenWebUI etc.<br />
I Made this to use the image models included on 8$ plan, but may work with other models too.

# Install

Edit node.py and put your NanoGPT api key on follow:
```
API_KEY = "sk-nano-XXXX-XXXX-XXXX-XXXX-XXXX"
```
